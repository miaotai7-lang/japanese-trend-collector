# V8.5.3 网络流行词：收录与审核规范

## 三种概念不再混淆

1. **有来源的网络流行表达**：在近期明确的青年语言调查、排名或正式趋势研究中出现，有日期、机构、可核实链接；人工整理日语读音、中文、英文与语境。默认显示，仅最近180天的证据算作“近期”。
2. **搜索话题**：Google Trends RSS 中的搜索查询可能是人名、品牌、赛事；记录在 topic 样本中，**不自动算流行语**。
3. **标题高频词**：指定 RSS 标题中同词的采样次数，任何普通名词、常用动词都可以上榜，但**明确标注非流行语**。

## 后台更新机制

GitHub Actions 继续按原来时间采集公共 RSS；新增 Google News RSS 的“若者言葉／流行語／ネットスラング”标题来源，用来**发现候选**。提取标题中的引用表达，保存到 docs/state.json -> slangReviewQueue。候选不会自动发布，也不会编造中英文。

可靠的含义与上下文往往无法从标题中得到：要审核新流行语，请更新 data/verified_slang.json（jp、kana、zh、en、date、rank、publisher、source、category、note），经过 PR 质量检查、合并、正式采集后才进入最新流行语列表。这样后台可自行发现、去重、登记；正式审核是质量保障，不是无依据的自动翻译。

**高频词模块**仍自动更新，继承原先的词典中英候选匹配与来源保存；只是不再误标为流行语。

## 不触碰私有数据

独立 GitHub 仓库读公共 RSS 并公布公共 feed.json；不含 Firebase 凭据，不读取私人词条，不改变 Firebase 的登录、同步或 Firestore 规则。网站升级包仅 deploy --only hosting。
